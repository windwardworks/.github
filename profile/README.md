# Windward Workshop

An independent game workshop. Small team, long horizons: two games in development,
built one verifiable change at a time.

| Game | What it is | Stack |
|---|---|---|
| [Tradewinds](https://github.com/windwardworks/tradewinds) | Isometric 2D business-tycoon + action-adventure RPG. Host-authoritative 4-player co-op. | Godot 4.4, GDScript |
| [Roguelike](https://github.com/windwardworks/roguelike) | A roguelike in early design. | Engine to be chosen |

Tooling and working agreements live in [workshop](https://github.com/windwardworks/workshop).
